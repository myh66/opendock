# 使用说明

## 首次启动

1. 按 README 构建并打开 `build/OpenDock.app`；可将应用放到 `/Applications` 后再打开。
2. 首次引导先选择使用方式、预览本地组件，再确认是否创建一个新布局。选择只在点击「开始使用」后生效；「稍后再看」保留当前设置。已有布局不会被新引导覆盖，可在设置或关于页重新查看。
3. 首次启动会尝试只读保存现有 macOS Dock 的固定应用布局，读取不会修改系统 Dock。从左侧选择布局，在编辑区添加应用、目录、文件、链接、间隔、应用组或组件。
4. 自定义布局切换后，独立 OpenDock 面板会显示该布局。在设置中选择屏幕、左／底／右位置、图标尺寸、材质和自动隐藏。

组件只属于 OpenDock 自定义面板，不能插入 Apple 的 Dock。启动或切换自定义布局不会关闭已有应用，也不会自动打开全部固定应用；点击应用或在应用组中选择应用才执行打开操作。

## 使用方式与外观

设置中的模式分别为「macOS Dock」「两者并用」「自定义为主」。前者管理系统布局；并用保留 Apple Dock，同时显示自定义面板；自定义为主会备份系统 Dock 的隐藏设置并在运行期间隐藏它。切换到自定义为主时会显示 OpenDock 面板，可另行开启自动隐藏。模式卡片上的选择会立即生效；引导中的选择只在最后确认时生效。

材质提供磨砂、深色、通透和 Liquid Glass。管理器、设置页和项目编辑器使用一致的分组与操作控件，支持浅色／深色及系统辅助显示设置。原生 Liquid Glass 需要 macOS 26 以上及支持该 API 的构建工具链；早期系统或旧工具链使用材质回退，保留所选配置。

自动隐藏时，指针移到相应屏幕边缘可显示 Dock；弹窗打开时保持显示。窗口预留空间只在自定义 Dock 可见、未自动隐藏且未启用桌面组件模式时生效，并需要辅助功能权限。设置页会说明不生效的原因。

## 编辑与拖拽

单击选择项目，⌘ 单击增减选中项，⇧ 单击选择一段项目；拖动时保持选中项的相对顺序。同一布局内拖动是移动，拖入另一个布局的编辑区、自定义 Dock 或编辑区末尾添加卡片会创建独立副本并保留源项目。macOS 类型布局只接收应用与分隔符。组件副本的通知开关会关闭，需要单独启用。

项目菜单可以编辑名称和图标或复制项目；应用组编辑器可添加、移除与排序应用。网站图标在点击读取后才访问输入地址；关闭编辑器、取消读取或修改地址会取消请求。图标缩小后保存在布局内，随 JSON 导出。

## 切换与自动化

菜单栏可直接切换两类布局。默认全局快捷键为 `⌘⌥1` 到 `⌘⌥9`，按保存顺序对应前九个布局；可在设置 → 布局快捷键中录制、修改或清除。录制至少使用两个修饰键，Escape 取消、Delete 清除；录制期间暂停全局布局切换。

**菜单栏、全局快捷键及设置中的 macOS 布局选择会直接应用系统 Dock 并重启 Dock**，不会只打开编辑器。管理页的「应用布局」按钮会先确认。若快捷键被其他程序占用，应用会提示，可重新录制或从菜单操作。自定义 Dock 范围内的方向滑动及 ⌘ + 滚轮可以切换自定义布局。

OpenDock 已提供原生 Focus Filter：系统设置 → 专注模式 → 添加过滤条件 → OpenDock，选择原生或自定义布局；结束专注模式后保留当前布局。快捷指令可搜索「切换 OpenDock 布局」，也支持两类布局。应用包中的 App Intents 元数据不代表系统已发现或已配置自动化，实际注册与触发需在目标 Mac 验证。

自定义布局可以通过以下 URL 激活：

```text
opendock://profile/布局的UUID
```

在设置 → 专注与自动化中复制当前布局链接，也可在快捷指令中使用「打开 URL」。URL 只允许切换自定义布局；URL 指向原生布局时会拒绝操作。

## 组件与权限

- 时钟、世界时钟、便签与本地计时不需要系统访问权限。专注计时／倒计时可主动开启结束通知；闹钟与独立饮水提醒在主动开启时申请通知权限。通知由系统排程，暂停、停用或移除组件会取消对应通知。计时状态、便签和饮水历史随布局保存。
- 日历／提醒事项在点击连接后申请 EventKit 权限，可选择日历或列表；日历显示未来 7 天安排及已识别会议的加入链接。完成提醒会修改系统提醒事项。拒绝授权时可在系统设置 → 隐私与安全性中调整。
- 正在播放使用 Apple Music 或 Spotify 的系统自动化接口；主动连接后可能出现权限提示。自动刷新只访问已经授权且运行中的所选播放器，可显示其提供的封面与进度。
- 天气搜索向 Open-Meteo 发送城市查询，选定城市后发送坐标，读取当前、小时与每日预报。可选择单位和刷新间隔；「使用当前位置」才申请定位权限。失败时保留带时间戳的缓存，超过 1 小时会标记为旧数据。
- 快捷指令列出并运行你本机的 Shortcuts；快捷指令自身可能请求其他权限。
- AirDrop 可接收拖入的文件与网页链接并保存草稿；点击发送才调用系统分享功能，实际接收状态由系统显示。
- 电池、系统与网络读取真实系统计数器；存储扫描只在主动选择范围后运行，无法读取的位置会报告部分结果。
- 应用窗口列表、恢复与最小化依赖辅助功能授权；在设置中主动允许。普通应用启动与注册的全局快捷键不需要该权限。

操作细节、保存行为和验证边界见 [本地组件与系统连接](LOCAL_WIDGETS.md)。

0.3.0 Beta 1 增加网易云音乐、IBKR、Ollama、Shadowrocket 四个入口。网易云音乐提供应用启动与官方收藏链接；IBKR 只读本机 Client Portal Gateway 的账本和持仓；Ollama 只读本机版本与模型状态；Shadowrocket 只读客户端安装／运行和系统代理摘要。它们分别需要已有客户端或服务，不能从一个入口的存在推断播放控制、交易、AI 生成或 VPN 控制已支持。连接步骤见 [外部数据连接](INTEGRATIONS.md)。

## 导入与导出

使用设置中的「导出」保存 JSON。文件包含布局、组件配置、便签、饮水记录和本机路径；保管好私人导出文件。

「导入」会校验格式并追加布局，重新生成标识符，同名布局会加上「（导入）」后缀。现有布局会保留，导入配置不会自动应用 Apple Dock。跨 Mac 的文件路径和应用位置需要手动检查。

## 原生 Dock 备份与恢复

1. 先在主窗口保存当前 macOS Dock 布局；长期保留的原始布局应另行导出 JSON。
2. 选择 macOS 类型布局，只添加有效 `.app` 和小／普通间隔。确认要切换后执行应用操作。
3. 修改前 OpenDock 将系统 Dock 偏好设置写入 `~/Library/Application Support/OpenDock/native-dock-backup.plist`。这是**上一次应用前的快照**，下一次应用会覆盖，只有一级恢复。
4. 应用只修改 `com.apple.dock` 的 `persistent-apps`；文件夹／下载项目与其他 Dock 设置不被改写。系统 Dock 会重启，随后验证固定应用和间隔；失败时尝试恢复本次操作前的列表，并显示结果。
5. 在设置 → 备份与本地数据中执行「恢复原布局」，可恢复最近快照中的固定应用和间隔。恢复也会重启系统 Dock，快照文件不会被该恢复操作覆盖。

这些功能已提供保护流程，仍需要你在使用的 macOS 上进行真机验证。若自动回滚也失败，请保留备份文件，记录错误信息；不要删除应用数据后再寻求恢复。管理员强制的 Dock 配置或未知项目可能使应用拒绝修改。

替换模式的隐藏设置另存于 `replacement-mode.plist`，只处理 `autohide`、`autohide-delay` 和 `autohide-time-modifier` 三个键，包括原来缺失的键。关闭替换模式或正常退出时恢复这些设置；不会借此恢复已应用的固定应用布局。若恢复失败，应用显示错误并暂停退出，应保留备份文件。强制退出或崩溃后，请重新打开应用并关闭替换模式以尝试恢复。

## 本地文件

```text
~/Library/Application Support/OpenDock/
  layouts.json                     布局、组件配置与本地记录
  native-dock-backup.plist          上一次原生布局应用前的快照
  replacement-mode.plist           替换模式原始隐藏设置（模式结束后清理）
  layouts-unreadable-<UUID>.json     配置无法读取时保留的副本（若出现）
  integrations/                    连接元数据与报告缓存，不包含服务密钥
```

布局使用原子写入；无法读取的文件会先保留副本，再创建默认布局。若副本保存也失败，应用暂停布局写入并显示错误。数据不是加密保险箱，不适合存储凭据。

## 退出、登录启动与卸载

关闭管理窗口不会退出 OpenDock；从菜单栏选择退出会移除独立面板与菜单栏，并恢复替换模式保存的隐藏设置。已经主动应用到 Apple Dock 的固定应用布局仍保留，需要还原时先恢复最近备份或重新应用自己保存的原始布局。

登录启动由 macOS `SMAppService` 管理，建议安装到 `/Applications` 后启用；系统可能要求批准后台项目。卸载前在 OpenDock 设置中关闭登录启动，然后退出并移除应用。若要删除私人数据，可在确认不再需要备份后移除上述 Application Support 目录。
