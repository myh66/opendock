# 功能对照与路线图

参照截至 **2026-10-08** 获取的 Dockset 公开资料；最新公开版本为 **0.2.6（2026-09-22）**。参考：[官网](https://dockset.app)、[更新记录](https://dockset.app/changelog)、[手册](https://dockset.app/manual)。下表比较能力范围，不复制其实现或产品素材。

「已实现」只代表代码提供了该行为；构建、单元测试与真机验证的界限单独记录在 [验证清单](VERIFICATION.md)。OpenDock 目前为开发 Beta，不能宣称完整复刻。

| 能力 | OpenDock 0.1.0 | 当前限制 |
| --- | --- | --- |
| 保存／切换自定义与原生布局 | 已实现 | 两种布局独立保存；原生布局需在编辑器中主动应用 |
| 应用、文件、目录、URL、间隔、应用组 | 已实现 | 原生布局仅支持应用和间隔 |
| 左／下／右、尺寸、材质、自动隐藏 | 已实现 | 不等同于 macOS 26 Liquid Glass；多显示器待验证 |
| 运行中应用、菜单栏与全局快捷键 | 已实现 | 原生快捷键打开编辑器；冲突、多 Space 待真机验证 |
| JSON 导入导出 | 已实现 | 私人路径需检查，跨 Mac 路径不自动迁移 |
| 原生 Dock 备份、应用校验与回滚 | 已实现，待真机验证 | 依赖系统偏好设置，重启 Dock；一级恢复 |
| 16 种本地／权限组件 | 已实现，权限操作待真机验证 | 逐项范围见下表 |
| Focus 自动切换 | 快捷指令／URL Scheme 替代路径 | 原生 Focus Filter 未实现 |
| 点击最小化、窗口列表 | 已实现，待真机验证 | 辅助功能授权依赖 |
| 缓存最小化窗口缩略图 | 未实现 | 无截图权限与缩略图缓存 |
| Stripe、Paddle、Shopify | 未实现 | 无商业账户接入 |
| AI Limits / Activity、股票与行情 | 未实现 | 无账号令牌读取、用量接口或行情数据 |
| 多选拖动、跨分隔线固定、轨迹板切换 | 未实现 | 编辑器范围以实际界面为准 |
| 自动更新、公证、App Store 分发 | 未实现 | 开源构建与本机签名脚本 |

## 组件范围

| 组件 | 数据或行为 | 验证边界 |
| --- | --- | --- |
| 时钟、世界时钟 | 系统时间与可选时区 | 本机时区设置 |
| 秒表、倒计时、专注计时 | 日期时间计算，状态存入组件配置 | 完成提示仅显示在界面，无系统闹钟通知；休眠和重启待真机验证 |
| 时间进度 | 日期区间进度 | 按本机日历计算 |
| 便签、饮水记录 | 本地文本与记录 | 导出文件可能包含内容 |
| 电池、系统状态 | 系统查询 | 设备可用性与系统 API 范围 |
| 日历、提醒事项 | EventKit；未来 7 天日历与未完成提醒各最多 30 条 | 用户主动连接与刷新；点击完成会修改系统提醒 |
| 天气 | Open-Meteo 城市搜索与当前天气，保存最近缓存 | 主动请求，无自动刷新；缓存超过 1 小时标记为旧数据 |
| 快捷指令 | 系统 Shortcuts | 需存在用户选择的快捷指令 |
| 正在播放 | Apple Music / Spotify 自动化 | 主动连接、刷新和控制；无通用媒体接口或后台轮询 |
| AirDrop | 系统分享面板 | 无自有传输协议；需可用接收设备 |

## 下一阶段

1. 真机验证权限、恢复、不同显示器和 Space 的行为，修正可访问性与键盘导航。
2. 可靠的窗口管理、布局拖动、状态持久化和原生 Focus Filter 扩展。
3. 逐项评估网络行情、商业与 AI 服务接口；只有具备真实数据源、明确授权和凭据保护后才标记完成。
4. Developer ID、公证、升级权限身份稳定性和可验证的发布流程。

这些是路线图，未承诺交付日期。开源许可不意味着与上游商业服务有合作关系。
