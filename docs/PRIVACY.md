# 隐私与数据流

OpenDock 不需要账户，没有分析遥测、内置云同步或自动上传布局的服务。下表描述当前代码的数据流。

| 数据 | 保存或接收方 | 触发条件 |
| --- | --- | --- |
| 布局、路径、便签、计时、饮水记录与天气缓存 | 本机 `~/Library/Application Support/OpenDock/layouts.json` | 编辑或组件状态变化时保存 |
| 系统 Dock 偏好快照 | 本机 `native-dock-backup.plist`，权限 `0600` | 用户主动应用原生布局前 |
| 布局 JSON 备份 | 用户选择的文件位置 | 主动导出；文件可能包含私人内容 |
| 日历标题与日期、提醒事项 | Apple EventKit；组件运行时读取 | 主动连接并授权后 |
| 提醒事项完成状态 | Apple EventKit | 点击完成某条提醒事项 |
| 曲目名、艺术家与播放状态 | Apple Music / Spotify 自动化；组件运行时内存 | 主动连接、刷新或控制播放 |
| 城市名查询 | `geocoding-api.open-meteo.com` | 主动搜索城市 |
| 选定城市经纬度 | `api.open-meteo.com` | 获取当前天气 |
| 文件或链接 | 用户选择的系统分享渠道／应用 | 点击文件、链接或使用 AirDrop |

天气服务也会接收普通网络请求包含的来源 IP。当前代码不使用定位权限自动寻找你的位置。天气数据来自 [Open-Meteo](https://open-meteo.com)，按 CC BY 4.0 提供；默认免费 API 仅允许非商业使用，其条款独立于 OpenDock 源码的 MIT License。参见 [服务条款与隐私说明](https://open-meteo.com/en/terms)。

日历与提醒事项内容不写入布局 JSON；正在播放曲目信息不长期保存。组件可保存选定播放器、时区、城市坐标、最近天气数据和快捷指令名称等配置。天气不自动后台刷新，超过一小时的缓存会标记为旧数据。外部应用、快捷指令、链接目标和系统分享服务有自己的数据处理行为。

辅助功能仅用于应用窗口管理，不记录键盘输入。全局快捷键使用系统注册接口，不请求输入监控权限。当前版本没有截图、屏幕录制、AI 账户读取或商业服务密钥收集功能。

本地配置未加密。JSON 导出、原生 Dock 快照及不可读配置副本可能暴露用户名或路径；分享前应脱敏。OpenDock 不上传这些文件，备份到 iCloud 等同步目录则由你选择的服务管理。

撤销权限可在系统设置 → 隐私与安全性中完成。删除数据、卸载及原生 Dock 恢复步骤见 [使用说明](USAGE.md)。
